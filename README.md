# bizluaMaprando
Tracker for map rando bizhawk

just download the code as a zip and extract it somewhere, open up lua console in bizhawk and open the sm.lua you unzipped and load your fav sm/maprando and you are set.

config.json format is [x, y, scale]
height option only works in windowed mode
roomver 1 truncates the room name to roomlen characters
font is configurable - only a select few fonts work if you choose one that isn't available you get no text.
